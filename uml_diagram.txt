### BaseRepository<T extends Identifiable>

- `- filePath: String` – Path to the storage file  
- `- header: String` – File header schema (column names)

- `+ BaseRepository(filePath: String, header: String)`  

**Abstract Methods:**
- `# mapToModel(row: List<String>): T` – Convert row → model  
- `# mapFromModel(model: T): List<String>` – Convert model → row  

**Methods:**
- `+ getFilePath(): String`  
- `+ getHeader(): String`  
- `+ readAll(): List<T>` – Read all records into models  
- `+ saveAll(data: List<T>): void` – Save all records to file  
- `+ append(model: T): void` – Append new record  
- `+ update(matcher: Predicate<T>, updatedModel: T): boolean`  
- `+ delete(matcher: Predicate<T>): boolean`  
- `+ findByKey(key: String): Optional<T>`  
- `+ updateByKey(updatedModel: T): boolean`  
- `+ deleteByKey(key: String): boolean`
